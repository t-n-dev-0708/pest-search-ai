# PestSearch AI (害虫検索 AI)

商談や現場ヒアリング中の会話をリアルタイムで音声認識・テキスト解析し、文脈に応じた害虫対策マニュアルや殺虫剤のSDS（安全データシート）を自動サジェストするWebアプリケーションです。

## 主な機能

- 常時音声聞き取り（Web Speech API）: ブラウザのマイクを利用し、バックグラウンドで連続文字起こしを行います。
- リアルタイム・ナレッジ自動サジェスト: 会話ログから害虫名を自動検出し、対応するマニュアルや殺虫剤資料を虫の種類ごとに分類して即座に画面表示します。
- Gemini AI による文脈自動補正: 音声認識の誤認識を、Gemini 2.5 Flash が害虫駆除の文脈を読み取ってワンタップで修正します。
- 検索・UI調整: ファイル名限定検索切り替え、テーマ切り替え（ダーク/ライト）、文字サイズ調整（S/M/L）、Google Drive連携枠を搭載しています。

---

## 使い方

1. 音声入力または手動入力による検索  
   - 商談中に常時起動しておくことで、会話から自動でリアルタイム文字起こしと資料検索を行います。  
   - 手動でキーワードを入力して直接検索することも可能です。
2. 参照先フォルダの指定  
   - 画面上部の入力欄から、検索対象としたいGoogleドライブのURLを指定することができます。

---

## このアプリのオリジナリティ

- ハンズフリー対話支援: 手動操作なしで、会話の流れに合わせて必要な資料が自動的にポップアップするリアルタイム提示体験を実現しました。
- AI専門用語補正: 現場の雑音や音声認識誤りを、害虫駆除分野に特化させたGemini 2.5 Flashで自動補正する仕組みを構築しました。

## 使用技術

- Frontend/UI: Streamlit
- Voice Recognition: Web Speech API
- AI Text Correction: Gemini 2.5 Flash API (google-genai)
- Data Handling: Pandas
- Image Processing: Pillow (PIL)

---

## デモンストレーション手順

1. 画面右下の「音声聞き取りを開始する」ボタンを押します。
2. マイクに向かって以下の台本を読み上げます。

> 厨房で発生しているゴキブリは、分布調査と殺虫剤駆除を提案します。
> 水回りのユスリカや、生ゴミ付近のショウジョウバエも、対策を進めます。

3. 会話ログから「ゴキブリ」「ユスリカ」「ショウジョウバエ」の資料カードが自動表示されます。
4. 誤認識がある場合はAPIキーを入力し、「AIで修正」ボタンを押して文脈補正を実行します。
